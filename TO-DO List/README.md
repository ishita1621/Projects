# 📝 To-Do List Application

A simple and responsive **To-Do List web application** built using **HTML, CSS, and JavaScript**. The application allows users to add, complete, delete, filter, and manage their daily tasks through a clean and interactive interface.

## 🚀 Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 🔍 Filter tasks based on their status
* 📊 Display the number of remaining tasks
* 💾 Store tasks using **Local Storage**
* 🔄 Restore tasks after refreshing the page
* 📱 Responsive design for different screen sizes
* ⚠️ Input validation for empty tasks

## 🛠️ Technologies Used

* **HTML5** – Structure and semantic markup
* **CSS3** – Styling, layout, responsiveness, and UI design
* **JavaScript (ES6+)** – Application logic and DOM manipulation
* **Local Storage** – Persistent task storage in the browser
